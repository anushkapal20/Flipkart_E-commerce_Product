> Flipkart E-Commerce Product Analysis

> Project Overview

This project analyzes the Flipkart E-Commerce Product Dataset using Python, MySQL, and Tableau. 
The dataset was cleaned using Python, analyzed using SQL queries in MySQL Workbench, and visualized through an interactive Tableau dashboard.

> Tools & Technologies Used

* Python (Pandas)
* MySQL Workbench
* Tableau Public
* VS Code
* GitHub
⸻
> Dataset Information

* Dataset: Flipkart E-Commerce Product Dataset
* Total Records: 29,870
* Data Cleaning: Removed null values using Python (Pandas).
⸻
> Project Workflow

1. Imported the Flipkart dataset into Python.
2. Cleaned the dataset by removing null values.
3. Saved the cleaned dataset as a CSV file.
4. Imported the cleaned CSV into MySQL Workbench.
5. Performed SQL queries to analyze product data.
6. Created an interactive Tableau dashboard for visualization.
7. Uploaded the complete project to GitHub.
⸻
> Dashboard Insights

The Tableau dashboard includes:

* Average Product Price
* Top Product Categories
* Top Brands
* Average Discount by Category
* Price Distribution
⸻
> Project Files

* flipkart_cleaned.csv — Cleaned dataset.
* flipkart_analysis.py — Python data cleaning script.
* mysql_queries.sql — SQL queries used for analysis.
* Tableau Dashboard — Data visualization dashboard.
